# Spotify-Mood-Analysis

## Project Overview
This project analyzes Spotify song features and classifies songs into different mood categories (Happy, Calm, and Sad) using Python. The cleaned dataset was exported from Google Colab and used in Power BI to create an interactive dashboard for mood-based music analysis.

## Dataset
Source Dataset: Spotify Features Dataset

Data Processing:
* Loaded and analyzed the Spotify Features Dataset in Google Colab.
* Created a new Mood column using the valence feature.
* Classified songs into Happy, Calm, and Sad categories.
* Cleaned and exported the processed dataset as **MoodMusicData.csv**.
* Imported MoodMusicData.csv into Power BI for dashboard creation.
